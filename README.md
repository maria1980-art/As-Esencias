# Salon landing page demo

Static, responsive HTML landing-page proposal for a fictional salon. The
business name, town, address, phone number, social link, and map destination are
sample values and must be replaced with approved details before real use.

## Preview locally

Open `index.html` in a browser. Google Fonts and the sample photography are
loaded from external services, so an internet connection is required for those
assets.

## Publishing with GitHub Pages

1. Open this repository's **Settings → Pages** on GitHub.
2. Select **Deploy from a branch**.
3. Choose the `main` branch and `/ (root)` folder, then save.
4. Wait for GitHub Pages to finish publishing and use the URL shown in Settings.

Review all business details, image usage, contact links, and content with the
business owner before publishing a real business site.
